# CinePedia Examen Certificación
Cinepedia es una aplicación web para gestionar un catálogo de peliculas con comentarios de usuarios.

## Descripción
Proyecto desarrollado para el examen final de certificación Full Stack Python. La plataforma permite a usuarios crear una cuenta, iniciar sesión y administrar publicaciones de películas mediante un CRUD completo con restricciones de autoría.

## Tecnologías utilizadas en mi examen:
- Backend: Python con Flask.
- Base de Datos: MySQL con relaciones.
- Seguridad: Encriptación de contraseñas con Bcrypt y manejo seguro de sesiones.
- Frontend: Plantillas Jinja2 con diseño responsivo mediante Bootstrap.

## Resumen de Modulos
- Modulo Usuarios: Registro e inicio de sesión seguro con validaciones y hash de contraseña.
- Modulo Peliculas: Creación, lectura, modificación y eliminación de registros.
- Modulo Comentarios: Sistema de retroalimentacion en cada pelicula.
